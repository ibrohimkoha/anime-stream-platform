# 🎌 Anime Streaming & VIP Community Platform

Next.js 15 App Router (Frontend) + Golang Gin REST API (Backend) + PostgreSQL + Backblaze B2 S3.

## 🚀 Stack
- **Frontend**: Next.js 15, React 19, Tailwind CSS, Framer Motion, Lucide Icons, Dark/Light mode, i18n (UZ/EN/RU).
- **Backend**: Golang 1.24/1.25, Gin Router, GORM, PostgreSQL, JWT Auth, Cron Auto-free scheduler.
- **Database**: PostgreSQL (Zero-Migration safe).
- **Domain**: `https://stream.hikaku.uz` & `https://api-stream.hikaku.uz`
